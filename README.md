## 📋 Описание проекта
Скрипт осуществляет автоматизированный сбор текстовых отзывов по заданному объекту («Сбербанк России») с распределением по 5 категориям оценок (от 1 до 5 звёзд).

### Выполненные требования:
1. **Программное создание директорий:** папки `dataset/1` ... `dataset/5` создаются средствами Python (`pathlib.Path`), ручное создание исключено.
2. **Форматирование файлов:** имена файлов содержат ведущие нули (`0000.txt`, `0001.txt`, ..., `0999.txt`), сформированные с помощью строкового метода `str.zfill(4)`.
3. **Исключение дубликатов:** реализован реестр уникальных ID отзывов (`set`).
4. **Уровни сложности:**
   - **Уровень 1:** сохранение аннотации отзыва со страницы списка (по умолчанию).
   - **Уровень 2:** переход по ссылке и загрузка полного текста отзыва (флаг `--full`).
5. **Контроль качества кода:** код строго проверен линтером `flake8` на соответствие **PEP8** (длина строк $\le 79$ символов, типизация, docstring).
6. **Дополнительный бонус:** проект дополнен интерактивным ноутбуком `lab1_notebook.ipynb` (Google Colab / Jupyter).
